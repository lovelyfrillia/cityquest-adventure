# CityQuest Adventure 개발 로드맵 및 전략

## 1. 제품 정의

**CityQuest Adventure**는 삼성혈의 목함상자에서 시작해, 시티퀘스트 탐험대가 길잡이의 단서를 따라 광양시장 골목을 탐험하고 칠성구슬 7개를 모아 곶자왈의 잠든 정령을 깨우는 현실연결형 모바일 웹 게임이다.

핵심 경험은 카드 수집 자체가 아니라 다음 행동을 계속하게 만드는 탐험 루프다.

```
길잡이의 힌트
→ 골목 탐험
→ QR 또는 현장 미션
→ 탐험대 이야기·구슬 획득
→ 다음 단서 해금
→ 7개 구슬 완성
→ 정령 각성 엔딩
```

## 2. 캐릭터 위계

| 구분 | 역할 |
|---|---|
| 시티퀘스트 탐험대 | 주인공. 여정을 수행하고 구슬을 모은다. |
| 목함상자의 길잡이 5명 | 힌트와 목적지를 알려준다. |
| 칠성구슬 7개 | 시즌 1의 진행 목표다. |
| 곶자왈의 정령 | 최종적으로 구해야 하는 존재다. |

## 3. MVP 목표

일주일 행사형 MVP에서 검증할 것은 하나다.

> 참가자가 첫 번째 단서를 받은 뒤 실제 골목을 이동해 두 번째 행동을 하는가?

### MVP 범위

- 모바일 웹/PWA
- 닉네임 또는 간편 참가
- 프롤로그 1개
- 길잡이 5명 중 1명 우선 구현
- 탐험대 주인공 화면
- QR 미션 7개 구조
- 칠성구슬 7개 상태
- 정령 각성 엔딩 1개
- 관리자용 미션 설정 파일
- 중복 획득 방지
- 새로고침 후 진행상태 보존

### MVP에서 제외

- 결제
- 실시간 GPS
- 전투
- 복잡한 회원가입
- 카드 교환
- 다중 시즌
- 앱스토어 배포
- 실시간 관리자 서버

## 4. 개발 단계

### Phase 0 — 세계관·데이터 고정

- 캐릭터 역할 고정
- 길잡이 5명 정의
- 칠성구슬 7개 정의
- 미션 상태 모델 정의
- 시즌 1 엔딩 문구 확정

완료 기준: 화면과 데이터에서 주인공·길잡이·정령의 역할이 섞이지 않는다.

### Phase 1 — 게임 코어

- 장면 전환
- 현재 챕터 상태
- 구슬 수집 상태
- 진행률
- 새로고침 복구
- 처음부터 다시 시작

완료 기준: 프롤로그에서 첫 구슬 획득까지 끊김 없이 진행된다.

### Phase 2 — 실제 캐릭터 연결

- 탐험대 이미지 개별 연결
- 길잡이 이미지 개별 연결
- 주인공 선택 또는 탐험대 소개
- 캐릭터별 한 줄 능력·대사

완료 기준: 모든 핵심 화면에 실제 캐릭터가 등장한다.

### Phase 3 — 현장 미션

- QR 7개 연결
- QR별 구슬 매핑
- 미션 완료 페이지
- 중복 스캔 방지
- 현장 안내 문구
- 미션별 다음 단서

완료 기준: 운영자가 QR 위치와 보상을 데이터만 바꿔 수정할 수 있다.

### Phase 4 — 정령 각성

- 7개 구슬 완성 화면
- 정령 실루엣 공개
- 각성 연출
- 시즌 1 완료 배지
- 결과 화면과 재방문 메시지

완료 기준: 참가자가 마지막에 명확한 결말과 보상을 경험한다.

### Phase 5 — 행사 QA

- 모바일 390×844
- 데스크톱 1440×900
- QR 실제 촬영
- 통신 불안정 상황
- 중복 촬영
- 뒤로가기·새로고침
- 운영자 체크리스트
- 개인정보 최소수집 점검

완료 기준: 행사 운영자가 개발자 없이 진행할 수 있다.

## 5. 운영 전략

### 행사 전

- QR 7개 위치 확정
- 각 위치에 안전한 표식 설치
- 참여점포와 역할 연결
- 구슬별 안내문 출력
- 현장 운영자 1명당 담당 구역 배정
- 테스트 계정으로 전 구간 완주

### 행사 중

- 참가자는 삼성혈 또는 행사 본부에서 시작
- 첫 길잡이 힌트를 받은 뒤 골목으로 이동
- 구슬 획득은 게임 보상으로 관리
- 소비쿠폰은 별도 회계·증빙 체계로 관리
- 운영자는 QR별 스캔 수와 오류만 확인

### 행사 후

- 첫 행동 전환율
- 2개 이상 구슬 수집률
- 평균 체류 구역
- 참여점포 방문률
- 완주율
- 재방문 의향
- 가장 인기 있는 탐험대원
- 가장 어려웠던 미션

## 6. 성공 지표

| 지표 | 1차 목표 |
|---|---:|
| 첫 QR 완료율 | 70% 이상 |
| 두 번째 미션 이동률 | 50% 이상 |
| 구슬 3개 이상 수집률 | 35% 이상 |
| 참여점포 방문 인증률 | 40% 이상 |
| 7개 완주율 | 15% 이상 |
| 오류로 인한 진행 중단 | 5% 이하 |

## 7. 개발 원칙

1. 먼저 재미있는 이동 흐름을 만들고 콘텐츠를 늘린다.
2. 실제 캐릭터와 실제 장소를 우선 연결한다.
3. 카드와 쿠폰을 같은 보상으로 섞지 않는다.
4. 운영자가 코드 수정 없이 미션을 바꿀 수 있게 한다.
5. 모든 화면에는 반드시 다음 행동을 둔다.
6. 정령은 초반에 전부 공개하지 않고 최종 보상으로 남긴다.
